# Поле количества в корзине: без гонок и случайного удаления

Written against: c6947a1

## Evidence chain

- Surface: `/cabinet/cart` — колонка «Кол-во» таблицы позиций
- Problem: `CabinetCartPage.tsx:108-118`: `onChange` инпута сразу вызывает `changeQuantity(productId, Number(value))`. Следствия: (1) пользователь стирает «1», чтобы ввести «15» — на пустой строке `Number("")=0` и позиция удаляется с сервера; (2) PUT уходит на каждый keystroke («1»→«15» = PUT 1, PUT 15); (3) параллельные PUT могут прийти не по порядку — итог непредсказуем.
- Design evidence: UX-конвенция «коммит количества по blur/Enter»; серверная семантика `quantity=0` = удаление (используется кнопкой «Убрать»)
- Owner: `frontend/src/pages/cabinet/CabinetCartPage.tsx`
- Scope and affected surfaces: только корзина кабинета; публичная витрина не имеет поля количества (out of scope)
- Uncertainty: нет

## Design decision

Разделить локальный ввод и сетевой коммит: значение держится в локальном стейте строки, коммит — по blur/Enter или debounce 600 мс; пустая строка не отправляется вообще (восстанавливается прежнее значение на blur); `0` как удаление остаётся только явной кнопке «Убрать»; на время полёта PUT инпут disabled, ответ сервера — единственный источник истины.

## Scope

- Inherit: пересчёт «Итого/НДС» продолжает приходить с сервера в `ServerCart`
- Verify: физлицо и юрлицо (одна и та же страница); пустая корзина (таблица не рендерит инпуты)
- Exclude: витринный «В корзину» (кнопка добавляет шаг — отдельное решение), складские поля количества (они локальные в модалке, гонок нет)

## Validation

- Product: изменить «1» на «12.5» → сумма и НДС пересчитались, позиция не удалилась; очистить поле → позиция жива; «Убрать» → позиция удалена
- Interface: клавиатура: Enter коммитит, Escape откатывает draft; tab-порядок сохранён; 390px
- System: единственный путь `quantity=0` — кнопка «Убрать»; инпут не отправляет PUT на keystroke (в коде нет `putCartItem` внутри onChange)
- Repository: добавить Vitest на helper валидации draft-строки (`parseQuantityInput: "" | "abc" | "0" | "12.5"`); `npm --prefix frontend run test` → зелёные

## Stop conditions

- Stop, если бэкенд `PUT /cart/items` не идемпотентен по последовательным вызовам (пересчёт от дельты) — тогда коммит только по blur без debounce и фикс на бэке отдельным тикетом.
