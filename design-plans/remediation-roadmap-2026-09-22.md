## Гейты решений владельца продукта

| Вопрос | Блокирует | Рекомендация по умолчанию |
|---|---|---|
| Валюта в интерфейсе: «Br» или «р.» | plan-05 | По бренд-буку: «р.» (ценник «42,50 р./кг»); если 1С требует «Br» — тогда «Br» везде, но единообразно |

| Семантические цвета статусов (успех/ошибка зелёно-красные?) | ничего срочного | Оставаться в бренд-палитре; вынести в отдельное решение при появлении требования |

## Общая валидация после каждой волны

- `npm --prefix frontend run lint` → без ошибок
- `npm --prefix frontend run test` → зелёные (сейчас 81+)
- `npm --prefix frontend run build` → сборка проходит
- Ручной проход: гость → корзина → заказ (физлицо); менеджер: взять заказ → статус → счёт из заказа юрлица; склад: создать/провести/отменить документ; админ: пользователи/товары/витринные флаги.
